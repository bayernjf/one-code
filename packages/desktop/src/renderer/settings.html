AI Watchdog 设置

监控目标

灵敏度

窗口内文件变更达到阈值判定为「工作中」，静默超过超时判定为「完成」。短于最短工作时长的任务只改状态不发通知，设为 0 表示不设门槛。

深度信号

VS Code 伴侣
开启后监听本地 socket，接收 VS Code 扩展上报的宿主内部信号（Copilot 活跃、终端写入等）。扩展需安装并启用伴侣模式。

通用

按下快捷键显示当前 AI 状态。留空表示不注册。格式参考 Electron Accelerator（如 Alt+Command+W、Control+Shift+A）。开启「仅失焦时通知」后，AI 工具在前台时不弹通知。

勿扰模式

勿扰期间完成通知静默。等待输入可能阻塞 AI，可选择仍通知。时段支持跨午夜（如 22:00-08:00）。

远程通知

配置后通知将同时推送到远程渠道。Webhook 接收 JSON POST；ntfy 需在手机装 app 并订阅同一 topic。留空禁用对应渠道。
